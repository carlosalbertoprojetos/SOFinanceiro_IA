# Planning readiness

- [ ] Pedido envolve múltiplos módulos, contratos, dados, integração ou fases?
- [ ] Existe risco material financeiro, operacional, de segurança, privacidade ou IA?
- [ ] Há migração, compatibilidade, rollout ou rollback coordenado?
- [ ] Ambiguidade restante muda materialmente abordagem?
- [ ] Estado atual pode ser inspecionado antes de perguntar?
- [ ] Lightweight plan é suficiente?
- [ ] Execução direta é segura, local e reversível?

Resultado obrigatório: `full plan`, `lightweight plan` ou `direct execution` com justificativa.
