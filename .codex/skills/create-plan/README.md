# Create Plan

Status: `experimental`, versão `0.2.0`.

Transforma mudanças complexas, ambíguas ou de alto risco em plano executável baseado no estado real. Decide antes se tarefa merece plano completo, lightweight plan ou execução direta.

Recursos:

- `references/planning-model.md`: classificação, aplicabilidade e composição;
- `assets/templates/`: plano completo, leve e de migração;
- `assets/checklists/`: readiness, qualidade, finanças e IA;
- `examples/`: planejamento complexo, tarefa trivial e caso limítrofe;
- `evals/`: acionamento, não acionamento, limites, comportamento e adversariais.

Sem dependências nominais. Skills especializadas são consultadas apenas quando acrescentam restrição material.
